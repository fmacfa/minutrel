# Fixtures de calcul

`donnees-exemple.json` et `temps-exemple.csv` décrivent un ancien format documentaire v1 : deux membres, un projet et 8 100 secondes (2 h 15). Le contrôle du dépôt vérifie leurs références et leurs totaux.

La V0.1 produit un export JSON v2 du travail partagé. L’import JSON n’est pas encore une fonction de l’application ; la restauration utilise la sauvegarde SQLite complète. Un [rapport PDF fictif](../../output/pdf/minutrel-rapport-demo-2026-11.pdf) illustre le moteur d’export courant.

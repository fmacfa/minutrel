# Intégrations V0.1

`mcp.ts` expose les outils personnels avec le SDK officiel. `ai.ts` valide les hôtes, chiffre les clés de profils, limite les générations et adapte Chat Completions ou Claude Messages. `integrations.test.ts` exerce le protocole MCP réel et les réponses de fournisseurs contrôlées.

Les assistants ne lisent pas les dossiers du disque et les moteurs de rédaction ne modifient aucun temps. Les modèles réels sont configurés par l’exploitant.

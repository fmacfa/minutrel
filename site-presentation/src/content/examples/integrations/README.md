# Exemples d’intégrations

Copier les fichiers `.example` et remplacer l’origine par celle de l’instance. Les exemples sont désactivés par défaut et ne contiennent aucune clé réelle. Créer un jeton personnel dans Les connexions et définir `MINUTREL_MCP_TOKEN` dans l’environnement du client.

Codex utilise `bearer_token_env_var` ; Claude Code utilise la variable dans l’en-tête Authorization. La liste d’outils Codex proposée exclut les commandes du chronomètre. Les profils de moteurs sont des exemples à reporter dans l’interface administrateur ; le serveur V0.1 ne charge pas automatiquement ce JSON.

Le point d’accès `/mcp` est implémenté et testé avec le client officiel. [Droits et fonctionnement](../../docs/INTEGRATIONS_IA.md).

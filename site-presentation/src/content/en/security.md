# Report a security problem

Minutrel is under development. No maintained application release has yet been publicly published.

Do not put secrets, team data or exploitation details in a public issue. Once a repository is published, use private GitHub vulnerability reporting if its maintainers enable it; otherwise request a private contact channel before sending details.

Before a public stable release, maintainers must specify supported versions and a private reporting channel. No response deadline is promised at this stage. The project’s security requirements are guidance, not a security certification.

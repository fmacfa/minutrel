# Changelog

## 0.1.0 — 2026-11-06

First functional Minutrel version: shared SQLite server, team accounts and permissions, projects/tasks, persistent synchronised timers, manual entries, reasoned corrections, notes and monthly summaries.

Monthly CSV/PDF/ZIP reports, shared-work JSON export and backup/restoration. Web and Tauri clients with widget, system menu icon and keychain session. MCP for Codex/Claude Code and optional Ollama/vLLM/Claude writing providers.

Standalone desktop use without a server, previous-state local storage, persistent offline team-time outbox, conflict checks and explicit transfer of personal entries. App interface and illustrated guides in French, English and German, with localised server report labels. Incoming private-draft webhook with a scoped token and idempotency.

Brand resources, specifications, locked dependencies, Docker images and three-platform CI definitions. Initial installers are unsigned. Invitations, general JSON workspace import, assisted conflict merging and outgoing webhooks remain future work.

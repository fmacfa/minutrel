Installer Minutrel sur Mac

Glissez Minutrel sur le dossier Applications dans la fenêtre du DMG. Ouvrez ensuite Minutrel depuis Applications.

Si macOS ne peut pas vérifier l’éditeur

L’application est signée localement, sans notarisation Apple. Si vous avez téléchargé cette copie depuis minutrel.com et lui faites confiance, vous pouvez confirmer son ouverture.

  1. Essayez une première fois d’ouvrir Minutrel dans Applications. Fermez l’alerte.
  2. Dans le menu Pomme, ouvrez Réglages Système, puis Confidentialité et sécurité.
  3. Faites défiler vers le bas jusqu’à la section Sécurité. À côté du message concernant Minutrel, cliquez sur Ouvrir quand même, puis confirmez.

Si le message dit « Minutrel est endommagée », téléchargez un nouveau DMG depuis la page d’installation. Aide Apple

Se connecter à son équipe

Dans Serveur de votre équipe, collez l’adresse que vous utilisez pour accéder à votre espace Minutrel dans le navigateur. Saisissez l’e-mail et le mot de passe de votre compte d’équipe, puis cliquez sur Entrer dans mon espace. Le bouton Vérifier permet aussi de tester l’adresse.

Si votre espace personnel est déjà ouvert, choisissez Paramètres → Ouvrir un espace d’équipe pour retrouver la connexion.

Install Minutrel on Mac

Drag Minutrel onto the Applications folder in the disk image. Open Minutrel from Applications.

If macOS cannot verify the developer

The app is signed locally and has not been notarized by Apple. If you downloaded this copy from minutrel.com and trust it, you can approve it.

  1. Try opening Minutrel once from Applications and dismiss the alert.
  2. From the Apple menu, open System Settings, then Privacy & Security.
  3. Scroll down to the Security section. Next to the message about Minutrel, click Open Anyway, then confirm.

If the message says “Minutrel is damaged”, download a fresh DMG from the installation page. Apple Support

Connect to your team

In the team server field, paste the web address you use for your team workspace. Enter your team email and password, then sign in. You can also check the server address before signing in.

If your personal workspace is already open, go to Settings and choose the option to open a team workspace.
